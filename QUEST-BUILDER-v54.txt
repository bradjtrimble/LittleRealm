Little Realm v54 — QUEST BUILDER + WORLD PACK

NEW
- Added Lilly and Jorge NPC sprite sheets to the town.
- Added config-driven NPC placement in config/npcs.js.
- Added data-driven quests in config/quests.js and src/quests.js.
- Added NPC conversations, ! / ? quest markers, quest acceptance/turn-in, rewards, save progress, and a compact quest log.
- Added Kill, Collect, Talk, Deliver, and Visit objectives.
- Added the first two starter quests: Lilly's Slime Samples and Jorge's Slime Problem.
- Added E as the keyboard Talk / Interact key. NPCs can also be clicked/tapped.

WORLD BUILDER
- Added an NPC tab for placing Lilly/Jorge/blank NPCs, moving them visually, and editing their properties.
- Added a Quest Maker with NPC dropdowns, objective editors, rewards, prerequisites, quest chains, repeatable toggle, and test-progress reset.
- Added a Project tab with a single World Pack export/import workflow.
- World Builder local drafts now save props + NPCs + quests + visual settings + combat tuning together.
- Existing v1 prop-only local drafts are still loadable.
- Individual world-objects.js, npcs.js, quests.js, visual-settings.js, and game-balance.js exports remain available.

RECOMMENDED WORKFLOW
1. Press F2 and make as many world/content changes as desired.
2. Use Project > Export World Pack (.json).
3. Upload little-realm-world-pack.json when you want those changes merged into the project source.

The single World Pack is intended to reduce the need for a new source build after every tiny world-editing change.
