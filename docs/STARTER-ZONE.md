# Starter Realm reference zone

Starter Realm is the current 44×32 development zone and production default. It is project content, not an engine-owned map template.

Its terrain grid, player start, placed objects, NPCs, mob spawns, quests, and World Beyond terrain live in `content/zones/starter-realm/world-pack.json`. Existing Slimes, Goblins, Wolves, farm animals, and Snickers are ordinary shared Mob Types; their placements are ordinary zone spawn records.

The old hard-coded houses, fence runs, physical location signs, and floating region labels were removed. Starter Realm can be redesigned freely with the same Terrain/Object/NPC/Spawn tools used for any newly created zone.
